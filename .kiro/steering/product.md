# Producto

Peliculas es una aplicación Java para gestionar un catálogo de películas, expuesta como API REST.

## Objetivos
- Gestionar el catálogo (alta, edición, borrado y consulta de películas).
- Permitir buscar y filtrar por título, género, año y director.
- Permitir valorar películas y mantener listas de favoritas o vistas.
- Servir como proyecto de aprendizaje de Java y Maven.

## Usuarios
- Administrador: gestiona el catálogo (crear, editar, eliminar).
- Público: consulta el catálogo, busca y valora películas.

## Interfaz
- API REST con endpoints JSON; no hay interfaz gráfica en esta fase.
